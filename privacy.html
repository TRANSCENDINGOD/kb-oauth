Privacy policy

Last updated: 28 October 2026

Who uses kb

kb is a personal tool used only by its owner, on the owner's own computer. It has no other users.

What data kb accesses

With the owner's permission, kb reads the owner's Gmail messages through the Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly. It cannot send, change or delete email.

How the data is used and stored

  • Messages are copied into a database file on the owner's computer, so the owner can search them.
  • Password-reset, sign-in-code and two-factor emails are skipped. Text that looks like a password or API key is masked before it is stored.
  • The data is not sent to any server run by kb. It is not sold, shared with third parties, used for advertising, or used to train AI models.

kb's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

The owner can revoke kb's access at any time at myaccount.google.com/permissions, and delete the local database file to remove all stored data.
